# Project goals

This firewall project is a learning project. Use development work to build an
understanding of:

- Firewall architectures, including rule evaluation, packet processing,
  enforcement, and platform boundaries.
- Build systems and how to organize, compile, link, and maintain a codebase.
- Writing effective tests in C++ to verify behavior and support reliable,
  maintainable codebases.

# Working approach

- Explain architectural choices and their tradeoffs as changes are planned.
- Prefer incremental, understandable implementations that support these
  learning goals.
- Explain relevant build and testing decisions, connecting them to the behavior
  they enable or verify.
- The current implementation is in C. The goal of learning C++ testing does not
  imply rewriting the implementation in C++.
